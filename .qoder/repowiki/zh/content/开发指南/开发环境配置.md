## 项目概述

浙杭企服财务CRM管理系统是一个基于HTML5 + CSS3 + JavaScript的云端财务管理系统，采用Supabase作为后端服务，支持用户认证、云端数据存储和多设备同步功能。该项目提供了完整的开发环境配置方案，包括本地开发、测试和生产部署。

## 开发环境要求

### 技术栈概览

该项目采用现代Web技术栈构建：

- **前端技术**: HTML5 + CSS3 + JavaScript (原生JS，无框架依赖)
- **后端服务**: Supabase PostgreSQL数据库 + Supabase Auth认证

- **开发工具**: VS Code + 浏览器开发者工具

### 系统要求

- **操作系统**: Windows 10/11, macOS 10.15+, Linux Ubuntu 18.04+
- **浏览器**: Chrome 90+, Firefox 88+, Edge 90+, Safari 14+
- **Node.js**: 16.x LTS (仅用于部署，本地开发可选)
- **内存**: 至少4GB RAM
- **存储**: 至少500MB可用空间

## Supabase项目配置

### 创建Supabase项目

1. **访问Supabase官网**：前往 https://supabase.com
2. **注册账号**：使用GitHub账号或邮箱注册
3. **创建新项目**：
   - 选择 **Singapore** 区域（亚洲访问较快）
   - 设置项目名称：`finance-crm`
   - 设置数据库密码：强密码（请牢记）
4. **等待项目创建完成**：约2-3分钟

### 获取API凭据

1. **进入项目设置**：点击左侧菜单 **Settings** (齿轮图标)
2. **复制API密钥**：
   - **Project URL**: `https://xxxxx.supabase.co`
   - **anon public**: `eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...`

### 执行数据库初始化脚本

1. **打开SQL Editor**：点击左侧菜单 **SQL Editor**
2. **新建查询**：点击 **New query**
3. **执行脚本**：复制粘贴 `database-setup.sql` 的完整内容
4. **验证执行结果**：看到 "Success. No rows returned" 表示成功

### 启用邮箱认证

1. **进入认证设置**：点击左侧菜单 **Authentication**
2. **启用邮箱提供商**：点击 **Providers**
3. **配置邮箱验证**：可关闭 "Confirm email" 开关（推荐先关闭，方便测试）

## VS Code开发配置

### 推荐插件

虽然项目是纯前端应用，但仍建议安装以下插件提升开发体验：

#### 代码格式化类
- **ESLint**: JavaScript代码质量检查
- **Prettier**: 代码格式化工具
- **EditorConfig**: 统一编辑器配置

#### 开发辅助类
- **Live Server**: 本地HTTP服务器
- **Auto Rename Tag**: HTML标签自动重命名
- **Path Intellisense**: 路径自动补全
- **Bracket Pair Colorizer**: 括号配对高亮

### VS Code设置推荐

创建 `.vscode/settings.json` 文件：

```json
{
    "editor.formatOnSave": true,
    "editor.codeActionsOnSave": {
        "source.fixAll.eslint": true
    },
    "eslint.validate": [
        "javascript",
        "javascriptreact"
    ],
    "files.exclude": {
        "node_modules": true
    }
}
```

### 项目根目录配置

创建 `.vscode/extensions.json` 文件：

```json
{
    "recommendations": [
        "dbaeumer.vscode-eslint",
        "esbenp.prettier-vscode",
        "ritwickdey.LiveServer"
    ]
}
```

## 常见问题排查

### Supabase连接问题

**问题**: 登录后页面空白
**解决方法**:
1. 检查浏览器控制台(F12)错误信息
2. 确认 `js/config.js` 配置正确
3. 验证Supabase项目URL和密钥
4. 检查网络连接和防火墙设置

**问题**: 注册时提示"Email already exists"
**解决方法**:
1. 使用不同邮箱地址注册
2. 直接登录现有账号
3. 清除浏览器缓存后重试

### 数据库权限问题

**问题**: 添加数据时提示"未登录"
**解决方法**:
1. 检查用户会话状态
2. 重新登录系统
3. 清除localStorage中的会话数据

**问题**: 数据无法同步
**解决方法**:
1. 确认Supabase连接正常
2. 检查网络连接
3. 验证用户认证状态

### 浏览器兼容性问题

**问题**: 某些功能在旧版浏览器中不工作
**解决方法**:
1. 使用Chrome最新版本
2. 检查JavaScript ES6+语法支持
3. 确保启用JavaScript

### 开发环境问题

**问题**: 本地服务器无法启动
**解决方法**:
1. 确认Node.js已安装
2. 使用Live Server插件
3. 检查端口占用情况

## 部署指南

### Vercel部署

#### 方案A: 网页部署（推荐）

1. **访问Vercel**: https://vercel.com/new
2. **登录GitHub**: 使用GitHub账号登录
3. **导入仓库**: 导入你的代码仓库
4. **等待部署**: 点击 **Deploy**
5. **获取URL**: 部署完成后获得在线访问地址

#### 方案B: CLI命令行部署

1. **安装Node.js**: 访问 https://nodejs.org 下载LTS版本
2. **安装Vercel CLI**:
   ```bash
   npm install -g vercel
   ```
3. **部署项目**:
   ```bash
   cd 工具\finance-crm
   vercel
   ```
4. **按提示操作**:
   - 首次登录：选择浏览器登录
   - 创建新项目：输入 `y`
   - 项目名称：直接回车使用默认
   - 目录：直接回车使用当前目录
